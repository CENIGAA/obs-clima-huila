# Fotos de colaboradores

Carpeta para las fotos de perfil del equipo del Observatorio Climático del Huila.

## Cómo subir una foto

1. Coloca el archivo en esta carpeta: `public/assets/equipo/`
2. Nómbralo en minúsculas, sin espacios ni tildes, con guiones. Ejemplo:
   `jorge-chavarro.webp`, `efrain-dominguez.webp`
3. Referénciala desde el código con ruta absoluta:
   `/assets/equipo/jorge-chavarro.webp`

## Formato recomendado

- **Formato:** `.webp` (mejor compresión) o `.jpg`
- **Proporción:** cuadrada 1:1 (foto de perfil)
- **Tamaño:** 400×400 px aprox. (suficiente para avatar; mantiene el peso bajo)
- **Peso:** idealmente < 100 KB por imagen
